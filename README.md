# Fake Profile Detection System

## 📌 Project Overview

This project predicts whether an Instagram profile is Fake or Genuine using Machine Learning.

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

## 🤖 Machine Learning Algorithm

Random Forest Classifier

## ✨ Features

- Fake Profile Detection
- Genuine Profile Detection
- Confidence Score
- Web Interface using Streamlit
- Model Saving (.pkl)
- Prediction History
